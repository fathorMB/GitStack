# Skills

Skills are Markdown runbooks for repeatable project procedures: how to run the tests, how to release, how to check a migration. The lead agent and its sub-agents read them. The app shows them. Nothing executes them.

Put one `.md` file per skill directly in this folder. Use `../templates/skill.md`. Any `.md` file here except this README is a skill; `status` in the frontmatter defaults to `active`.
