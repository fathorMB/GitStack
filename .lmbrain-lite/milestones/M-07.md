# M-07 — CLI gs e skills per agenti

## Outcome

Un agente di coding, con la CLI gs e il pacchetto di skills, gestisce repo e issues su GitStack come oggi fa con gh su GitHub.

## Tasks

- [ ] T-01 CLI gs in Go su client generato da OpenAPI, licenza Apache-2.0
- [ ] T-02 gs auth login/status con token e config per più istanze
- [ ] T-03 Comandi gs repo (create, list, view, clone)
- [ ] T-04 Comandi gs issue (create, list, view, comment, close, edit) con etichette e milestone
- [ ] T-05 Output JSON stabile e codici di uscita documentati per ogni comando
- [ ] T-06 Comando gs api per chiamate API generiche
- [ ] T-07 Pacchetto skills: installazione e login, lavorare su una issue fino al commit, triage issues, gestione repo
- [ ] T-08 Distribuzione: binari multipiattaforma e installazione in un comando
- [ ] T-09 Prova reale: un agente completa una issue end-to-end usando solo gs e le skills
