`gs` is the GitStack command-line tool for people and coding agents. It talks
to an instance through the public API.

The reference pages are generated at build time from the real command tree
(`github.com/spf13/cobra/doc`), so they always match the shipped binary.
Start from [`gs`](./reference/gs.md) and follow the **SEE ALSO** links, or use
the sidebar.

:::note
Command descriptions and help texts are taken verbatim from the tool and are
currently in Italian.
:::
