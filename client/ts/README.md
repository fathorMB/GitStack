# client/ts

Client TypeScript generato dal contratto OpenAPI unico di GitStack
(`../../api/openapi.yaml`) con [`@hey-api/openapi-ts`](https://heyapi.dev/)
(devDependency in `package.json`, versione pinnata, risolta via `pnpm-lock.yaml`).

- `src/generated/**`: **generato**, non modificarlo a mano — ogni file porta
  l'intestazione `This file is auto-generated by @hey-api/openapi-ts`.
  Include tipi, client `fetch` e funzioni SDK per tutte le operazioni del
  contratto (`getHealth`, `listResources`, `createResource`, `getResource`,
  `updateResource`, `deleteResource`). Nessuna dipendenza a runtime oltre
  `fetch` nativo.
- `openapi-ts.config.ts`: configurazione del generatore (sorgente, output,
  plugin: client `fetch`, tipi, SDK).

## Rigenerare

Dalla radice del monorepo (comando unico, rigenera anche il client Go):

```sh
go work sync
./scripts/generate-api.sh
```

Oppure solo questo pacchetto:

```sh
cd client/ts
pnpm install
pnpm run generate
```

## Uso

```ts
import { client, getHealth } from "@gitstack/api-client";

client.setConfig({ baseUrl: "https://example.invalid" });
const { data } = await getHealth();
```

Pensato per essere consumato da `web/` (SPA React, M-01 T-07) come
dipendenza di pacchetto, senza funzioni esclusive della UI: lo stesso
contratto serve anche `client/go` e in futuro il server MCP.
