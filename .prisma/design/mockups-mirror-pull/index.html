Pause mirror
Stop updates for now. The repository stays a read-only mirror; resume with one click.
Resume mirror
Updates restart now, then every 10 minutes.
Stop mirroring
The repository becomes a normal, writable repository. Source credentials are deleted; run history and diverged refs stay. You can enable a pull mirror again later.
