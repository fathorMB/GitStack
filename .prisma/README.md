# Prisma kit

Prisma is a local analysis and knowledge brain for software products. The first consultation and open-note MCP slice is implemented in prisma-core and prisma-mcp; installation automation and analysis mutations are subsequent work.

Analysis sessions read AGENT.md; coding sessions read CODING.md. The existing coding setup remains in the project. See contract/data-model.md, contract/mcp.md and contract/migration.md for implementation contracts.

Knowledge is readable Markdown with stable artifact IDs and wikilinks. Product direction and the analysis journey are separate collections. Keep original sources and navigable Design mockups in the project. No account is required.

Templates contain placeholder IDs and dates: instantiate them with real values rather than treating template examples as existing artifacts. The server supplies validated consultation and note-addition operations; further mutations and the app will follow. Do not activate this scaffold by overwriting the project's current brain or host configurations.
