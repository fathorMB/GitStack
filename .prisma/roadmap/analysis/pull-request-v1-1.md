# v1.1 — Pull Request: regole di prodotto

## Expected learning

Regole di prodotto per le Pull Request della v1.1 (obiettivo "v1.1 — Collaborazione"), abbastanza precise da scrivere contratto API, mockup e test. Il server MCP della v1.1 è un tema separato, da aprire dopo.

## Scelte confermate dall'operatore (2026-10-05)

PR1–PR11, testo completo in [[knowledge/topics/pull-request]]: solo branch dello stesso repo; approvano le persone con `write`, gli agenti fanno review senza approvazione valida; merge commit e squash; "Richiedi una Pull Request" sul branch principale senza eccezioni per gli admin; commenti sulle righe con conversazioni risolte; bozze e tre stati; conflitti mostrati e risolti in locale; parole chiave anche nella descrizione con chiusura al merge; stati dei commit da sistemi esterni, obbligatori a scelta; flusso degli agenti nelle skills e comandi `gs pr`; notifiche e webhook delle PR.
